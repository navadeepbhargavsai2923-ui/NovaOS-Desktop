# NovaOS

NovaOS is a lightweight, XFCE-based Linux distribution project
targeting x86_64 PCs.

## Initial target
- Base: Xubuntu 24.04 LTS
- Desktop: XFCE
- Architecture: amd64
- Target hardware: Intel Core i3, 12 GB RAM

## Status
Project setup stage. A bootable ISO must be built and tested
before it is considered a release.
